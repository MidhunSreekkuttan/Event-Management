# 🎉 Event Management Web Application

A modern web application that allows users to explore events, send enquiries, and book events easily.  
The system also includes a staff dashboard to manage enquiries and suggest events based on user budgets.

---

## 🚀 Features

### User
- Browse available events
- View event details
- Send event enquiries
- Book events
- Secure online payment
- Receive email confirmation

### Staff Dashboard
- View user enquiries
- Manage enquiry status
- Suggest events based on budget

### Event Management panel
- Manage events
- create and shedule events
- Manage bookings

### Admin Panel
- Manage events
- Manage clients
- Track bookings
- Generate reports

---

## 💳 Payment System

Integrated online payment for event booking.

- Secure transaction process
- Payment confirmation
- Booking status update

---

## 📧 Email Notifications

Automatic email notifications for:

- Booking confirmation
- Enquiry responses
- Event updates
- user Login
- User signUp
